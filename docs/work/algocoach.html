THE PROBLEM

Start with the question.

Choosing the next practice problem is difficult when a rating alone says little about which algorithmic concepts need attention.

THE APPROACH

A decision that matters.

Weight topic relevance more heavily than rating in the feature vector, then use K-nearest neighbors to rank problems with an explanation of each match.

How it fits together

  1. 01Codeforces submissions
  2. 02Weak-topic analysis
  3. 03Weighted feature vectors
  4. 04Top-5 / Staircase practice

Simplified flow based on the documented implementation.

THE RESULT

What the work shows.

The application supports targeted Top-5 recommendations and a confidence-to-stretch Staircase. Async fetching and a disk cache reduce repeated upstream requests.

THE TAKEAWAY

What I’m taking forward.

Useful recommendations need context: exposing matched tags and rating differences makes the ranking easier to understand.

Next improvement
Evaluate whether recommendations help users improve over time; a recommendation score alone cannot establish a learning outcome.
